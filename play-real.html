Setup Guide for Real Game
STEP 1
Click the button below to copy the **AI Posture Controller** script to your clipboard.
STEP 2
Right-click anywhere on the game screen to the left and select **Inspect**, then go to the **Console** tab.
STEP 3
Change the console context from **top** to the game frame context (e.g. choose the entry containing **gamedistribution.com** in the dropdown).
STEP 4
Paste the copied code in the console, press **Enter**, click **START CAM** in the widget, then click **CALIBRATE** to stand still and start playing!
