# Subway Surfers AI

A 3D Subway Surfers web game powered by Three.js and Vite, featuring AI controller and pose tracking capabilities.

## Features

- **3D Subway Endless Runner**: Built with Three.js rendering tracks, obstacles, and player movement.
- **AI & Pose Controller**: Control gameplay gestures and AI navigation.
- **Interactive Audio**: Dynamic sound effects and background audio.
- **Fast Development**: Powered by Vite.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- `npm`

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

Then open [http://localhost:5175](http://localhost:5175) in your browser.

## Controls

- **Left / Right**: `A` / `D` or `ArrowLeft` / `ArrowRight` (Change lanes)
- **Jump**: `W` or `ArrowUp` / `Space`
- **Roll / Duck**: `S` or `ArrowDown`
- **AI / Pose Mode**: Use your webcam for motion and gesture detection.

## Tech Stack

- **Graphics**: [Three.js](https://threejs.org/)
- **Bundler & Dev Server**: [Vite](https://vitejs.dev/)
- **AI & Computer Vision**: Web-based pose estimation & gesture detection
- **Audio**: Web Audio API
